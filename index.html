Cập nhật tin tức học tập, công nghệ và lập trình Web cho sinh viên.

  • Bài 1: Nhập môn HTML
  • Bài 2: Sử dụng Chrome DevTools
  • Bài 3: Quản lý mã nguồn với Git

Bài 1: Cấu trúc cơ bản của một trang HTML

HTML sử dụng các thẻ ngữ nghĩa như header, main, article và footer để tổ chức nội dung rõ ràng, giúp trình duyệt và công cụ tìm kiếm hiểu đúng cấu trúc trang web.

Bài 2: Kiểm tra giao diện bằng Chrome DevTools

Nhấn phím F12 trên trình duyệt Chrome để mở tab Elements, giúp quan sát cây DOM trực tiếp và nhanh chóng phát hiện các đường dẫn ảnh hoặc liên kết bị lỗi.

Bài 3: Lưu trữ phiên bản code đầu tiên với Git

Sử dụng git status để theo dõi thay đổi, git add để đưa file vào vùng chờ và git commit để lưu lại từng cột mốc hoàn thiện của dự án web.
